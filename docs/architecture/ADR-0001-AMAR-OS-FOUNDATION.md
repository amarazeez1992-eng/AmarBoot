# ADR-0001 — تأسيس AMAR TRADING OS

## الحالة
معتمد — تنفيذ مرحلة التأسيس.

## القرار
تطوير AmarBoot تدريجيًا إلى AMAR TRADING OS مع الحفاظ على الكود الحالي. كل قدرة جديدة تكون وحدة مستقلة وتتصل عبر عقود واضحة.

## قواعد إلزامية
1. أضف ولا تهدم.
2. لا إعادة بناء شاملة للمشروع.
3. لا حذف للكود القديم دون موافقة صريحة.
4. فصل UI عن منطق التداول.
5. Demo أولًا؛ لا تداول حقيقي في هذه المرحلة.
6. لا إضافة لأي بوت جديد في هذه المرحلة.
7. LIVE موجود كحالة معمارية فقط، ويظل معطلًا.

## المرحلة الحالية
- App Shell
- Room Navigation
- Aurora Design System
- Motion Engine
- Centralized App State
- Internal Event Bus
- Feature Flags
- Operating Modes
- Module Manifest

## خارج النطاق الآن
- إضافة بوتات جديدة.
- ربط MT5 للتداول الحقيقي.
- استبدال محرك Grid الحالي.
- حذف أو إعادة كتابة GridControlScreen.

## سبب القرار
إنشاء أساس قابل للتوسع يمنع تحول التطبيق إلى شاشة واحدة ضخمة ويجعل إضافة غرف ومؤشرات وأدوات وأنظمة تداول مستقبلية ممكنة دون كسر الوحدات القائمة.
