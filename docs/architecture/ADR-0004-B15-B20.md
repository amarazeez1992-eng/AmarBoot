# ADR-0004 — B15-B20 Observability, Explainability, Guardian, Security, Audit and Supervisor

## Status
Accepted / Implemented (Demo-only foundation)

## Decision
Build B15-B20 as independent, provider-agnostic modules over the existing B1-B14 contracts. They are read-only from the trading perspective and must fail closed.

## Scope
- B15: deterministic bounded analytics.
- B16: immutable decision provenance and explanation.
- B17: Guardian policy evaluation.
- B18: security runtime state and emergency lock.
- B19: bounded structured audit records with basic secret-key filtering.
- B20: read-only Supervisor recommendations.

## Safety boundary
No module in this ADR can enable live trading, call a broker, access credentials, or place an order. The existing DEMO-only boundary remains authoritative.

## Approved architectural extensions
Clock abstraction, repository boundaries, future correlation/sequence metadata, deterministic testing, idempotency, structured observability, and resilient external-adapter patterns are part of the long-term architecture. AI Agent and AMAR Trading Library are approved future capabilities and are introduced here only as isolated contracts/foundations.

## Rationale
This creates a traceable chain from runtime telemetry to analytics, explanation, safety, security, audit and supervisory recommendation without coupling the UI to execution logic. Future Room/encrypted storage, indexed knowledge, AI providers, broker adapters and simulation can replace implementations behind stable contracts.
