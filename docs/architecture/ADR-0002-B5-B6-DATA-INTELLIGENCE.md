# ADR-0002 — B5 Data Fabric + B6 Intelligence Foundation

## الحالة
منفذ — Demo-only.

## القرار
إضافة طبقتين مستقلتين فوق الأساس المعماري دون إعادة بناء المحرك الحالي:

`Market Data → B5 Data Fabric → B6 Intelligence → Evidence Fusion → Decision Validation → UI`

## B5
B5 هو عقد بيانات موحد للبيانات السوقية والحساب والمراكز والأوامر وحالة البوت والمخاطر. يبدأ بمصدر DEMO deterministic، مع واجهة `AmarDataProvider` تسمح بإضافة مصدر حقيقي لاحقًا دون تغيير المستهلكين.

## B6
B6 يحول البيانات إلى أدلة وسياق سوقي وتحليل قابل للتفسير. لا يضع أو يعدل أو يغلق أي صفقة. `DecisionValidation` يمنع التنفيذ في وضع DEMO.

## قواعد السلامة
- لا LIVE trading.
- لا broker calls من B5/B6.
- لا قرار تداول داخل UI.
- لا إضافة بوتات جديدة.
- AMAR GRID الحالي محفوظ.
- الوحدات مستقلة وقابلة للاستبدال.

## سبب القرار
الفصل بين البيانات والتحليل والعرض يمنع تشابك الواجهة مع التداول، ويجعل إضافة MT5 أو مصادر أخرى لاحقًا عملية استبدال مصدر بيانات لا إعادة بناء للنظام. هذا يتوافق أيضًا مع مبدأ data fabric القابل للتركيب، ومع الحاجة إلى دمج الأدلة مع حدود واضحة للثقة والتفسير.
