## Admission rules

1. Unknown, missing, or incompatible licensing is release-blocking.
2. A public URL alone is not treated as permission to copy third-party code or content.
3. Third-party source reuse must retain its original license, notices, attribution, and applicable terms.
4. Transitive dependencies are not implicitly approved by this table; the release dependency graph is the authoritative generated inventory for the exact build.
5. No credentials, proprietary restricted code, or paid/invite-only source is admitted into the repository.
6. Any dependency version change requires re-audit of license and provenance before release closure.

## Project license boundary

AMAR-owned source code is licensed under the repository `LICENSE` (MIT). That license does not relicense third-party dependencies or third-party content.
