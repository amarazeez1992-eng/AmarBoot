# AMAR Open-Source Policy

AmarBoot is intended to be a transparent, auditable open-source trading platform.
The repository license applies to AMAR-owned source code only.

## Third-party source

A public URL is not automatically permission to copy or redistribute code.
Before reuse, AMAR must record:

- original source URL
- repository/project name
- exact license or terms
- version/commit/date when available
- required attribution
- modifications made by AMAR
- validation status

Protected, invite-only, paid proprietary, credentialed, or otherwise restricted
content is not copied into the project.

## Research evidence

Research sources are classified as SOURCE, HYPOTHESIS, INFERENCE, VERIFIED,
or another explicit evidence state. Search-result convergence is never presented
as a probability of trading success.

## Trading execution

Open source does not mean unrestricted live execution. The project remains
fail-closed: AI authority, risk gates, authentication, idempotency, ACK,
read-back verification, and reconciliation remain mandatory before broker execution.
