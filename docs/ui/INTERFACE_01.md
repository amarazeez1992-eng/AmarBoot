# واجهة رقم واحد

الحالة: **محفوظة كمرجع واجهة — غير نهائية**.

المصدر الفعلي للواجهة:
- `app/src/main/assets/amar_reference.html`
- الصورة المرجعية المستخدمة داخلها: `app/src/main/assets/amar_home_reference.png.png`

## قاعدة المقارنة
هذه الواجهة هي **واجهة رقم واحد**. لا تُعتبر الواجهة النهائية للتطبيق، ولا تُحذف أثناء تجربة الواجهات الأخرى.

عند طرح واجهات لاحقة ستُسجل كواجهة رقم 2، رقم 3، ... ثم تتم المقارنة والاتفاق على واجهة نهائية واحدة.

## مكونات الواجهة رقم واحد
- واجهة بيضاء كاملة الشاشة.
- مركز بصري دائري ثلاثي الأبعاد/تفاعلي.
- عقد وأزرار دائرية مرتبطة بالغرف.
- شريط علوي للوصول إلى مركز القيادة والحسابات والسوق والإعدادات.
- وصول مباشر إلى السوق والبوت والرسم البياني والمخاطر والتحليل.
- شريط سفلي للرئيسية والتنبيهات والأداء والمزيد.
- مؤشرات حالة حية، ساعة حية، نبضات تفاعلية وتأثير لمس.
- الربط مع `Android.openRoom()` و`Android.openHome()` لفتح غرف التطبيق.

## قرار هندسي
تُحفظ هذه الواجهة مستقلة كمرجع بصري ولا يُسمح لواجهة تجريبية لاحقة باستبدالها دون قرار صريح لاحقًا. تطوير الغرف الداخلية يتم بشكل مستقل عن المرجع البصري.
