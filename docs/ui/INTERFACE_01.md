# واجهة AMAR AI الرئيسية

الحالة: **واجهة AMAR AI الحالية قيد التحقق النهائي**.

## المصدر الفعلي
- `app/src/main/assets/amar_ai_workspace.html`
- `frontend/app/page.tsx`
- `frontend/app/globals.css`

## القرار الحالي
هذه هي واجهة الدخول الحالية للتطبيق وواجهة مساحة AMAR AI. تم إخراج الواجهة التجارية/التداولية القديمة من مسار العرض الفعلي.

الواجهة الجديدة لا تمنح نفسها سلطة قرار أو تنفيذ؛ مسارها:

`UI → AMAR AI Engine Boundary → Result / Evidence → UI`

## المكونات
- شاشة دخول رئيسية متحركة ثلاثية الأبعاد/زجاجية.
- مساحة Agent مركزية.
- AI Assistant.
- Research.
- Workspace.
- Files.
- Memory.
- Settings البصرية.
- حالة Fail-Closed ظاهرة.
- رفع الملفات والصور من الواجهة دون ادعاء تنفيذ أو تحليل غير موثق.
- الصوت والكاميرا ومشاركة الشاشة ظاهرة كقدرات مؤجلة للربط المعتمد في Stage 10.

## قاعدة التحقق
وجود زر أو عنصر بصري لا يساوي وجود قدرة محرك. أي قدرة غير مربوطة ومثبتة تبقى غير متاحة/غير مؤكدة.

لا يُعلن إغلاق هذه المهمة قبل تنفيذ دورة:

`تحقيق → تنفيذ → فحص → اختبار → تأكيد → إثبات → تدقيق نهائي → جاهز → إغلاق`
