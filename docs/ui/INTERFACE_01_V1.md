# واجهة عمار — V1 المعتمدة

الواجهة الرئيسية المعتمدة للتطبيق هي **Interface 01 / V1**.

## قواعد V1
- خلفية بيضاء.
- التصميم الدائري/الغرفي هو الهوية الرئيسية.
- النقاط والمناطق التفاعلية تفتح غرف التطبيق.
- لا تُستبدل الواجهة الرئيسية بواجهة داكنة أو Aurora.
- Interface 02 محفوظة كواجهة مستقلة مرجعية ولا تستبدل V1.
- كل الغرف الداخلية تستخدم لغة بصرية متوافقة مع V1.
- النص الظاهر للمستخدم بالعربية؛ الأرقام الإنجليزية مسموحة.
- التداول الحقيقي لا يُفعّل من الواجهة وحدها؛ يجب اجتياز بوابات الأمان وقناة MT5.

## غرف V1 الأساسية
- مركز القيادة
- الحسابات
- السوق
- الإعدادات
- مختبر البوتات
- الرسم البياني
- المخاطر
- التحليل
- التنبيهات
- الأداء

هذه الوثيقة تثبت V1 كمرجع واجهة التطبيق، مع إبقاء Interface 02 محفوظة دون حذف.
