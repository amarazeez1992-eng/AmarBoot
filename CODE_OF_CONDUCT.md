# Code of Conduct

AmarBoot is intended to be a professional, respectful open-source engineering project.

Participants are expected to:

- communicate respectfully and constructively;
- focus criticism on code, evidence, and decisions rather than people;
- disclose security issues responsibly;
- respect licenses, attribution, privacy, and intellectual property;
- avoid harassment, discrimination, threats, spam, and malicious behavior.

Maintainers may remove contributions or restrict participation when conduct violates
these standards or creates a security, legal, or project-health risk.
